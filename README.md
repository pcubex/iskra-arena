# Іскра Арена — Сезон Панді 🌿🐼

Самостійна українська HTML5/PWA-гра для телефону й комп'ютера. Сім оригінальних героїв, шість арен, чотири режими, укриття в кущах, локальний прогрес, окремі здібності, а також режим зомбі.

## Публікація на GitHub Pages

1. Створіть **публічний репозиторій** GitHub (наприклад, `iskra-arena`).
2. Завантажте **всі файли з кореня цього ZIP** в корінь репозиторію (`index.html`, `.nojekyll` та решту). Не вкладайте всю гру в додаткову теку.
3. Відкрийте **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
4. Виберіть **Branch: main**, папку **/(root)**, натисніть **Save**.
5. Коли публікація завершиться, адреса буде формату `https://USERNAME.github.io/REPOSITORY/`.

Усі шляхи відносні (`./`), тому гра має працювати і в підкаталозі проєктного сайту GitHub Pages, і в корені користувацького сайту. `sw.js` використовує лише власний шлях репозиторію й працює через HTTPS. Після внесення змін підніміть номер `VERSION` у `sw.js`, щоб оновився офлайн-кеш.

## Гра

- **7 героїв:** Рись, Бастіон, Комета, Віхола, Грім, Верба, **Панді**.
- **6 арен** із відмінними перешкодами й кущами для засідок.
- **4 режими:** Кристали, Захоплення прапора, Зомбі-навала, Мисливці.
- **Механіка кущів:** герой усередині заростей невидимий для противника поза тією ж зоною, якщо той далі ніж ~88 одиниць і герой не розкрив себе. Постріл розкриває позицію приблизно на 1–1,35 с. Гравці в одних кущах бачать один одного. Кущі прохідні. Боти й зомбі враховують приховування при виявленні цілей. Фізичні постріли все одно можуть влучати всліпу.
- **Панді:** два бамбукові паростки за атаку; суперуміння **«Бамбуковий гай»**: створює тимчасове укриття на 9 с і лікує Панді. Амулет підсилює лікування й дає короткий захист.
- **Кубки, досвід, амулети, одяг і поліпшення** з локальним збереженням.

На клавіатурі: `WASD`/стрілки — рух, `Пробіл` — атака, `E` — суперуміння, `Escape` — пауза. На телефоні: джойстик та великі сенсорні кнопки.

## Перенесення прогресу з Netlify

Прогрес зберігається в `localStorage` у ключі `iskra.adventure.v1`. Коли змінюється домен, браузер не переносить його автоматично.

На **старому** сайті відкрийте інструменти розробника → Console та виконайте:

```js
copy(localStorage.getItem('iskra.adventure.v1'))
```

Якщо `copy` недоступний, виконайте `localStorage.getItem('iskra.adventure.v1')` і вручну скопіюйте текст. На **новому** сайті відкрийте **«💾 Перенесення збережень»**, вставте скопійований JSON і натисніть **«Відновити з коду»**.

## Структура

- `data.js` — герої, карти, конфігурації кущів і режими;
- `game.js` — гра, ШІ, прогрес і механіки бою;
- `art.js` — оригінальні процедурні Canvas-спрайти й арени;
- `style.css` — адаптивний оригінальний інтерфейс;
- `manifest.webmanifest`, `sw.js` — PWA та робота без мережі;
- `icon.svg`, `icon-192.png`, `icon-512.png` — новий образ Панді.

**Важливо:** це незалежна гра з оригінальним кодом і процедурними ілюстраціями. Захищені ресурси інших ігор не використовуються. GitHub Pages — статичний хостинг; мережевий PvP потребуватиме окремого серверного компонента.
